# HungarianVisaBot

Telegram-бот, который следит за появлением слотов записи на подачу документов на венгерскую визу
(VFS Global, Беларусь: Hungary Visa Application Center, Minsk — `short term visa C` / `Short-Term VISA 90 days`)
и сообщает в Telegram, когда места появились.

Бот **только наблюдает и уведомляет**: ничего не бронирует, пароль не хранит, капчу не обходит.
Вход в аккаунт и проверку Cloudflare вы проходите вручную один раз; сессия хранится в профиле браузера.

## Установка

Нужен Node.js 22+.

```bash
npm install
npx playwright install chromium   # либо укажите свой браузер в CHROMIUM_PATH
cp .env.example .env
npm run build
```

## Настройка `.env`

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `ALLOWED_USER_IDS` | Telegram id через запятую (узнать: [@userinfobot](https://t.me/userinfobot)); остальным бот не отвечает |
| `VFS_CENTER`, `VFS_CATEGORY`, `VFS_SUBCATEGORY` | что проверять (по умолчанию Minsk / short term visa C / Short-Term VISA 90 days) |
| `CHECK_INTERVAL_SEC` | интервал проверки, минимум 60 (по умолчанию 180; ±20% случайного разброса) |
| `PROFILE_DIR`, `STATE_FILE` | профиль браузера и файл состояния |
| `HEADED` | `1` — показывать окно браузера |
| `CHROMIUM_PATH` | необязательно: путь к своему Chromium |

`.env`, `profile/` и `state.json` в git не попадают.

## Первый вход и запуск

```bash
npm run login   # откроется браузер: войдите в VFS и пройдите проверку Cloudflare
npm start       # запуск бота
```

Когда сессия истечёт или Cloudflare потребует проверку, бот один раз напишет «нужен повторный вход» —
повторите `npm run login`; проверки возобновятся сами.

## Команды бота

- `/status` — последний статус, время проверки, состояние сессии
- `/check` — внеочередная проверка (не чаще раза в 60 с)
- `/pause`, `/resume` — остановить / продолжить мониторинг

Уведомления приходят только при **смене** статуса: «Появились слоты» (со ссылкой на запись) и «Слоты закончились».
Также бот сообщает о потере сессии, блокировке со стороны портала, ошибке конфигурации
и о 5 неудачных проверках подряд (не чаще раза в час).

## Развёртывание на VPS

Cloudflare чаще пропускает не-headless браузер, поэтому на сервере без экрана используйте виртуальный дисплей:

```bash
sudo apt install xvfb
HEADED=1 xvfb-run -a npm start
```

Для входа (`npm run login`) нужен реальный экран: выполните его на своём компьютере и скопируйте каталог
`PROFILE_DIR` на сервер, либо подключитесь к серверу по VNC/X-forwarding. Для автозапуска подойдёт systemd-юнит или `pm2`.

## Разработка

```bash
npm test         # юнит- и сквозные тесты (e2e идёт против локальной заглушки портала в реальном Chromium)
npm run lint
npm run typecheck
```

Если для e2e Chromium лежит не в стандартном месте, задайте `CHROMIUM_PATH`; без браузера e2e пропускается.
Планирование и спецификации — в `openspec/`.

## Оговорки

- Использование VFS регулируется их условиями. Бот делает редкие запросы (≥ 60 с, с разбросом) и не обходит защиту;
  решение о его использовании остаётся за вами.
- Тексты и селекторы портала могут измениться: они вынесены в `src/classifier.ts` и `src/browser.ts`.
  При неопределённой странице бот сообщает `UNKNOWN`, а не «слоты есть».
