# Proposal

## Why

Запись на подачу документов на венгерскую визу в Hungary Visa Application Center (Минск) на VFS Global почти всегда показывает «нет доступных слотов»; места появляются на короткое время и без анонса. Ручное обновление страницы неэффективно — нужен бот, который сам следит за доступностью и сразу сообщает в Telegram.

## What Changes

- Новый Telegram-бот, который периодически проверяет доступность слотов на `https://services.vfsglobal.by/blr/ru/hun/` для выбранной комбинации: центр `Hungary Visa Application Center, Minsk`, категория `short term visa C`, подкатегория `Short-Term VISA 90 days`.
- Определение статуса по странице «Информация о подаче документов»: сообщение «нет доступных слотов» → слотов нет; отсутствие сообщения и активная кнопка «Продолжить» → слоты есть.
- Уведомление в Telegram только при **смене** статуса (нет → есть), без спама; команды управления (`/status`, `/check`, `/pause`, `/resume`).
- Управление VFS-сессией: вход через постоянный профиль браузера, контроль истечения сессии и оповещение владельца.
- Бот только **наблюдает и уведомляет**; бронирование слота выполняет человек.

## Capabilities

### New Capabilities
- `slot-monitoring`: периодическая проверка доступности слотов для настроенной категории визы и определение изменения статуса.
- `vfs-session`: поддержание авторизованной сессии на портале VFS, обнаружение её потери и защитных проверок (Cloudflare) без их обхода.
- `telegram-bot`: доставка уведомлений и команды управления для авторизованных пользователей Telegram.

## Impact

- Новый проект с нуля (репозиторий пуст): код бота, конфигурация, документация запуска.
- Внешние системы: Telegram Bot API, портал VFS Global (Беларусь).
- Секреты (токен бота, учётные данные VFS) — только через переменные окружения/локальный профиль, не в репозитории.
- Юридический/этический момент: использование VFS регулируется их условиями; частота запросов ограничена, обход капчи не предусмотрен.
