# Spec Delta

## Purpose

Поддерживать авторизованную сессию на портале VFS Global для проверок и честно сообщать, когда требуется участие человека, не обходя защитные механизмы портала.

## ADDED Requirements

### Requirement: Вход с участием человека
Система SHALL использовать постоянный профиль браузера, в котором владелец один раз входит в аккаунт VFS вручную, включая прохождение проверки Cloudflare.

#### Scenario: Первичный вход
- **WHEN** профиль не содержит действующей сессии и бот запущен в режиме входа
- **THEN** открывается видимый браузер на странице входа, и система ожидает завершения входа владельцем

#### Scenario: Повторное использование сессии
- **WHEN** профиль содержит действующую сессию
- **THEN** проверки выполняются без повторного ввода данных

### Requirement: Без обхода защиты
Система SHALL NOT использовать сервисы решения капчи или иные средства обхода проверок Cloudflare/портала.

#### Scenario: Показана проверка Cloudflare
- **WHEN** во время проверки отображается интерактивная проверка, которую нельзя пройти без человека
- **THEN** проверка прерывается статусом `UNKNOWN`, и владельцу отправляется запрос на ручное вмешательство

### Requirement: Контроль состояния сессии
Система SHALL обнаруживать истечение сессии и уведомлять владельца.

#### Scenario: Сессия истекла
- **WHEN** портал перенаправляет на страницу входа
- **THEN** проверки приостанавливаются, владельцу отправляется одно сообщение «нужен повторный вход», повторные сообщения не рассылаются, пока вход не выполнен

#### Scenario: Сессия восстановлена
- **WHEN** владелец повторно вошёл
- **THEN** проверки возобновляются автоматически, владелец получает подтверждение

### Requirement: Защита учётных данных
Система SHALL хранить секреты вне репозитория и не выводить их в логи и сообщения.

#### Scenario: Логирование
- **WHEN** система пишет журнал ошибок входа
- **THEN** в журнале нет пароля, токена бота и cookies
