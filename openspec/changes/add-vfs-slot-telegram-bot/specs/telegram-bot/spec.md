# Spec Delta

## Purpose

Доставлять владельцу уведомления о доступности слотов и позволять управлять мониторингом командами в Telegram.

## ADDED Requirements

### Requirement: Ограничение доступа
Система SHALL отвечать на команды и отправлять уведомления только Telegram-пользователям из заданного белого списка.

#### Scenario: Неизвестный пользователь
- **WHEN** команду присылает пользователь не из белого списка
- **THEN** бот не выполняет команду и не раскрывает состояние мониторинга

### Requirement: Уведомление о появлении слотов
Система SHALL отправлять каждому подписчику сообщение при событии «слоты появились», содержащее категорию, время обнаружения и ссылку на страницу записи.

#### Scenario: Слоты появились
- **WHEN** публикуется событие «слоты появились»
- **THEN** каждый пользователь из белого списка получает сообщение со ссылкой `https://services.vfsglobal.by/blr/ru/hun/application-detail`

#### Scenario: Слоты пропали
- **WHEN** статус сменился с `SLOTS_AVAILABLE` на `NO_SLOTS`
- **THEN** отправляется короткое сообщение «слоты закончились»

#### Scenario: Сбой доставки
- **WHEN** Telegram API недоступен
- **THEN** отправка повторяется с задержкой, событие не теряется

### Requirement: Команды управления
Система SHALL поддерживать команды `/status`, `/check`, `/pause`, `/resume`.

#### Scenario: Запрос статуса
- **WHEN** пользователь отправляет `/status`
- **THEN** бот отвечает последним статусом, временем последней проверки и состоянием сессии

#### Scenario: Внеочередная проверка
- **WHEN** пользователь отправляет `/check`, и с последней проверки прошло не меньше минимального интервала
- **THEN** запускается проверка и бот присылает её результат

#### Scenario: Пауза и возобновление
- **WHEN** пользователь отправляет `/pause`, затем `/resume`
- **THEN** периодические проверки останавливаются, затем продолжаются

### Requirement: Оповещение о неисправностях
Система SHALL сообщать владельцу об устойчивых сбоях (несколько `UNKNOWN` подряд, блокировка, ошибка конфигурации).

#### Scenario: Серия неопределённых результатов
- **WHEN** получено 5 подряд результатов `UNKNOWN`
- **THEN** владелец получает одно сообщение с причиной, следующее — не раньше чем через час или после восстановления
